# ARC Architecture

## Overview

ARC is designed as a stablecoin-first blockchain ecosystem. Instead of adding stablecoins as an application layer, ARC integrates them into the foundation of the network to support payments, settlements, and financial applications.

---

## Architecture Goals

- Stablecoin-first design
- Native USDC integration
- High-performance execution
- Low-cost transactions
- Simple developer experience

---

## Main Components

### ARC Network

The blockchain provides the infrastructure for building financial applications powered by stablecoins.

### Native USDC

USDC is a core asset within the ecosystem, enabling efficient payments and transfers.

### App Kit

App Kit helps developers integrate wallets, authentication, and payment flows with less development effort.

### Developer Tools

ARC offers documentation, SDKs, and APIs to simplify building and deploying applications.

---

## Key Takeaways

One of the most interesting ideas is that ARC starts with stablecoins as the foundation instead of adapting an existing blockchain later. This approach creates a more consistent experience for developers building financial products.
